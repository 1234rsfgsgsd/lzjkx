# 朗思渡共享版

每位使用者的昵称、偏好保存在自己浏览器的 localStorage，PAST 练习、图片和录音保存在浏览器 IndexedDB；服务器不保存长期练习历史。旧版 localStorage 记录首次打开时会迁移，数据库写入成功后才清理旧副本。同一浏览器配置中的其他使用者也能查看本地记录；清理网站数据会删除它们。

## 本地运行

需要安装 Node.js 20 或更高版本。配置一个兼容 OpenAI Chat Completions、并且明确支持图片输入的视觉模型服务：

```powershell
$env:VISION_API_URL = '服务商提供的 chat/completions 地址'
$env:VISION_API_KEY = '你的服务密钥'
$env:VISION_MODEL = '支持图片输入的模型名称'
node server.js
```

然后打开 `http://localhost:3000`。API 密钥只在服务器环境变量中设置，不要放到 `index.html`。

## 讯飞真实录音诊断（本地试用阶段）

本版本的讯飞接入默认关闭。先在讯飞开放平台注册/登录，创建应用，在能力管理中开通 **语音评测（流式版）**，并在控制台确认当前账号的免费额度和计费规则。创建/开通后取得该应用的 `APPID`、`APIKey`、`APISecret`。实际免费额度以你的应用控制台为准；不要因为“新用户”宣传或本站调用次数限制，就假定不会计费。

在本目录将 `.env.example` 复制为 `.env.local`，填入现有 `VISION_API_URL`、`VISION_API_KEY`、`VISION_MODEL`、可选 `SPEECH_MODEL`，以及讯飞变量：

```dotenv
XFYUN_ISE_ENABLED=true
XFYUN_APP_ID=你的APPID
XFYUN_API_KEY=你的APIKey
XFYUN_API_SECRET=你的APISecret
```

安装本项目依赖后，运行 `node server.js` 并打开本地网页。在第二次录音评分处勾选“同时评测真实录音（讯飞）”。第二次录音和润色稿会上传到讯飞；接口失败时原录音仍保留，且不会自动重新提交收费请求。任何密钥只写入 `.env.local` 或托管平台的服务器环境变量，不要提交 Git，也不要发到聊天里。

语音评测以 16kHz 单声道 PCM 发送；网页会在本机把录音转码，单次录音限制在 3 分钟以内。本站不设置每日或每月硬上限，只记录本站实例已提交的调用次数；是否还能调用、是否计费、剩余额度都以讯飞控制台为准。当前免费 Render 实例的本地计数在重启或重新部署时可能重置。接入测试通过后，才把密钥加到 Render Environment；并先由教师抽样核对分数，再面向全体用户开放。

本接口当前会真实评估讯飞返回的朗读准确度、流利度与词级对齐；语速和长停顿由词级时间戳估算。它不会因英式/美式偏好自动选择两套发音评分口音，独立的语调/重音与可理解度分数如无供应商可靠字段则显示“待评”，不会凑成 100 分。未勾选语音模式时按评分标准使用转写文本模式：语法 35%、词汇 30%、内容完成度 35%。

## 部署到 Render 给同学和老师

### 可选：百炼直接音频反馈（AI参考评分）

新增音频评估与讯飞分开配置，默认关闭，且每次评分需单独勾选同意发送录音到百炼。只补充重音语调（10分）、可理解度（15分），不替代讯飞和实际转写分析。

```dotenv
AUDIO_REVIEW_ENABLED=false
AUDIO_REVIEW_API_URL=业务空间的OpenAI兼容Base URL/chat/completions
AUDIO_REVIEW_API_KEY=仅填到本地.env.local或Render环境变量
AUDIO_REVIEW_MODEL=qwen3.8-omni-flash
```

API URL、密钥和模型必须属于同一地域及业务空间。不要修改现有 VISION_* 或 XFYUN_* 配置；不订阅额外套餐也可按百炼实际规则按量调用。先本地配置，使用自己的测试录音运行 `node tests/audio-review-live-smoke.cjs <wav路径>`；文件需16kHz单声道16位PCM WAV，3秒到3分钟。该命令会发送录音并可能产生供应商费用，不自动重试。端到端测试通过后，再在Render启用 AUDIO_REVIEW_ENABLED=true。

百炼直接听第二次录音，不接收参考稿或用户转写，避免把看稿理解当作听辨。返回独立听辨内容、两项分数、中文理由、估计的片段时间及建议。缺少证据、低置信度、无有效语音、接口超时或余额不足时仍显示待评，并保留讯飞及文本结果。仅八项全部可评时显示综合参考分，缺项不补零、不缩放。

这些是未经人工校准的AI参考评分，不是讯飞官方新增指标或标准化考试分。模型自报置信度、片段时间和建议均可能有误，需回听核对；英美提示不等于经过验证的分口音评分。真人录音与教师对照验证是后续校准工作，合成语音联调不能代替。PAST及导出文件会保留补充音频反馈。

单元与任务验证：`node --test tests/audio-review.test.cjs`。网页回归：`node tests/xfyun-browser.cjs`，覆盖独立同意、补评分展示与失败保留讯飞结果。无需新增NPM依赖。

1. 把 `朗思渡共享版` 目录上传到你自己的 GitHub 仓库。不要提交真实 `.env` 文件或 API 密钥。
2. 在 Render 选择 **New + → Blueprint**，连接该 GitHub 仓库，并选择其中的 `render.yaml`。
3. Render 要求填写 `VISION_API_URL`、`VISION_API_KEY`、`VISION_MODEL`。在 Render 控制台的环境变量中填入所选视觉模型服务给出的值。
4. 为了让长文本评测更快，可在同一个 Environment 页面增加 `SPEECH_MODEL`。如果使用 SiliconFlow，常用值是 `deepseek-ai/DeepSeek-V3`；它只负责文字评测，`VISION_MODEL` 仍然保留图片识别模型。模型名称必须是你的账号有权限调用的模型。
5. 等待部署完成，打开 Render 提供的 `https://...onrender.com` 网址测试，再把网址发给同学和老师。

免费实例可能在一段时间无访问后休眠，首次打开会稍慢。公开网址意味着任何访问者都能调用照片识别；识图当前按 IP 每分钟限制 24 次，其他提交接口各自限制 12 次、单图限制 10 MB。上线前请在托管平台设置使用量提醒，并按服务商规则选择可承受的用量/计费方案。

如果暂时不想用 GitHub，也可以先在本机测试：安装 Node.js 20+，在 PowerShell 中设置模型环境变量后运行 `node server.js`。本地地址只供本机使用，不是同学可访问的公网网址。

当前接入层要求视觉服务兼容 OpenAI Chat Completions 的图片输入与 JSON 输出格式。DeepSeek 可用于文本生成，但若所选 DeepSeek 模型/API 不接受图片，就不能单独识图；需配置支持图片输入的视觉模型服务。网页识图后返回场景和物体，之后仍可使用本地练习历史。

## 站主主题图库

“随机图片”采用“选主题 → 从该主题图库随机选一张照片 → 原有识图接口提取关键词、英美音标、短语和例句 → 口语练习”的流程。图片全部由站主提供，不调用图片生成模型，也没有预置插画或演示图。

已按站主提供的“图片素材.zip”中的文件夹名称导入 334 张照片，覆盖 11 个主题：日常生活 39、餐饮美食 21、出行交通 38、旅游观光 35、工作职场 8、休闲娱乐 102、购物消费 11、宠物动物 17、运动健身 8、自然风景 27、学习校园 28。医疗健康暂未提供素材，继续显示“等待添加照片”；不会改用其他主题、生成图或占位图。上传自己的照片、识图、两轮录音、润色、最后评分和 PAST 记录继续可用。

照片存放在 `gallery/`，按 `gallery/manifest.json` 中主题的 `images` 清单选取。支持 JPG、PNG、WebP，单张不超过 10 MB；照片添加步骤见 `gallery/README.md`。仅清单中的文件会公开，图片应在站主确认后再添加。多张照片时“换一张”会避开上一张；主题只有一张时明确提示。

接口：`GET /api/gallery` 返回各主题照片数量，`GET /api/gallery/random?category=主题&exclude=上一张编号` 返回随机照片。取图本身不调用 AI；取图后的识图仍使用已有视觉服务及识图次数。旧的图片生成与预置插画接口返回 410，不会调用供应商。图片生成模型配置已从程序移除，无需设置 `SCENE_IMAGE_*`。

可选的 `GALLERY_DIRECTORY` 和 `GALLERY_MANIFEST_FILE` 仅供维护者更改图库目录和清单位置；默认直接使用随仓库发布的 `gallery`。不要把管理员维护目录当作访客上传接口。

## 评测、发音和本地备份

练习采用两轮流程：第一次自由口述只纠错和润色，`phase: polish` 不要求也不返回任何评分。用户可听示范，再照润色稿完成第二次录音；系统保留两次独立音频和转写，核对第二次转写并点击评分后，才以 `phase: final` 提交实际第二次转写及参考稿。参考稿只辅助判断内容完整度，不能代替实际朗读内容来评分。最终结果不会覆盖第一轮的纠错或润色稿。重录第二次会使旧评分失效；最终评分失败可保留两次录音重试。

新版最后评分分两种模式：转写文本模式按语法35%、词汇30%、内容完成度35%计算；勾选讯飞真实录音诊断后，结合供应商返回的实际音频指标与第二次实际转写显示评分标准的可评维度。缺失的维度显示“待评”，不生成虚假的八项综合分。结果是学习反馈，不能保证找出全部错误；服务失败时不提供估算分数。第二轮可在不支持浏览器语音识别但支持录音的设备上录制，停止后需回听并手动填写实际读出的内容；没有实际转写时，讯飞模式只提供可获得的音频指标，不会把润色稿当作转写。旧客户端未选择新版 oral-v1 标准的请求保留原有五维文字评测兼容方式。

词句与润色稿使用当前英美偏好播放，支持逐句、整段、停止、0.7/0.88/1/1.15倍速。播放依赖设备安装的声音，缺少对应口音时会提示。切换偏好立即更新 IPA 和播放语言，并重新生成当前图片提示；已有润色稿需点击重新评测以统一对应拼写和词汇。

PAST 可导出含图片、两轮文稿、两次有效录音、第一轮修改结果和最后评分的 JSON 备份，也可校验导入、去重合并和确认清空。只完成第一轮时也可先保存，此时没有分数。导入不更改个人偏好。不保存临时 blob 地址；旧版已失效录音不能恢复。备份应自行保管，当前没有账号或自动跨设备同步。提交识图/评测时相关数据会发送给模型服务，短期评测任务保留在服务内存中十分钟，重启可能丢失；断线时网页会重连同一个任务，服务重启后可手动重试。

验证：`node --test tests/*.test.cjs`；安装 Playwright 后运行 `node tests/browser-regression.cjs` 和 `node tests/workflow-regression.cjs`，浏览器测试使用模拟服务验证失败、重连、录音、播放、备份和移动端流程。

## 使用次数与练习记录

- 在词句区域填写“我想聊的是……”可按自己的表达目标重新分析当前图片；失败保留原有词句。相同浏览器、照片、英美偏好、学习水平和意图的识图结果在内存中复用十分钟，服务重启后失效。
- 每个浏览器默认每日识图 20 次、润色与最后评分合计 20 次。同一网络共享上限为浏览器额度的五倍。环境变量 `DAILY_VISION_LIMIT`、`DAILY_SPEECH_LIMIT` 可调整，按北京时间午夜重置。次数不是个人账号额度。
- `USAGE_STATE_FILE` 可指定计数文件，默认在系统临时目录。Render 重新部署或替换临时实例时可能重置；多实例需共享数据库。失败任务退回本站次数，不代表供应商退费。
- 居中的小狼等待卡显示随机取图、实际识图、完成三个阶段，并显示时间与取消按钮。取消保留已显示图片，已提交的识图请求可能仍产生费用。余额不足时不会自动重复提交任务。
- 三栏文稿对比、原文引文、时态复核和不确定结果提示保持不变。第一轮只纠错润色，第二轮才评分；可选讯飞真实录音诊断默认关闭，需开通服务并完成本地真实测试后再上线。
- PAST 保留两次录音、文稿、导出导入、备份提醒和持久存储申请。记录存于各自浏览器，换设备需导出再导入；同一浏览器配置中的其他使用者仍可查看本地记录。

验证：`node --test tests/*.test.cjs`；Playwright 浏览器回归为 `tests/browser-regression.cjs`、`tests/vision-jobs-browser.cjs`、`tests/workflow-regression.cjs`、`tests/topic-gallery-browser.cjs`。测试图片仅在临时测试环境中使用，不会加入站主图库；模型服务在回归测试中模拟。`PLAYWRIGHT_MODULE` 可指定 Playwright 路径。

如果网站面向中国大陆公众提供服务，部署前需核实托管平台和网站备案要求。
