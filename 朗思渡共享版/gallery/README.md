网站副本保持原文件名主体，转换为 WebP，最长边不超过 1600 像素，质量参数 90；不裁剪画面，移除元数据。原始 ZIP 不修改、不提交仓库。每项 `source` 记录压缩包中的原相对路径，`file` 指向网站副本；跨主题重复的原素材保留用户指定的分类。

维护者可使用 `python scripts/import-topic-gallery.py <素材zip路径>` 导入新的按主题文件夹打包的素材，需要 Pillow。脚本先校验全部图片，再写入清单；遇到未知主题、异常路径或已有目标文件会停止，不覆盖现有图片。

站主可以按主题发送文件夹或压缩包，之后由维护者放入这个目录并更新 `manifest.json`。仅清单中的图片可被随机选中，未列入清单的文件不会自动公开。

例如，收到“餐饮美食”图库后，可把照片存为 `food/001.jpg`，在对应主题的 `images` 数组中加入：

```json
{"file":"food/001.jpg","label":"咖啡馆点单"}
```

也支持直接填写 `"food/001.jpg"`。路径相对于本目录，不要写本机绝对路径或网址。支持真正的 JPG、PNG、WebP 图片，单张不超过 10 MB；其他格式请先转换。用户选完主题后只会从这个主题随机取一张，至少两张时“换一张”会避开上一张。图片仍通过原有识图接口自动提取场景与词句。
